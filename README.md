# Calculadora de Carrinho de Compras

## Sobre o Projeto
Aplicativo Android desenvolvido com Jetpack Compose para processar um catálogo de produtos e calcular valores de carrinho de compras. O sistema aplica regras de negócio na camada de domínio (funções puras), formata textos com limites de linhas, trata valores nulos de forma segura e exibe um processamento funcional de coleções no Logcat.
